## Overview

This project predicts customer credit limits using machine learning regression models.

## Features

- Data cleaning and preprocessing
- Missing value imputation using KNN
- Outlier handling using IQR clipping
- Feature scaling
- Regression model comparison
- Machine learning pipeline implementation

## Models

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Best Model

Random Forest achieved the best performance with an R² score of 0.83.

## Deployment

The trained model is deployed as a REST API using FastAPI.
